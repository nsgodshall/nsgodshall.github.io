Meshtastic is an open-source project that turns cheap LoRa radios into a long-range mesh network — the kind of off-grid setup that keeps working when there's no cell service and no internet. This was my experiment in putting a language model on the other end of that link, so you could send a question over the mesh and get an answer back without ever touching the wider network.
